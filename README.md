# سایت فرم مشاوره آقای عضله

این پروژه یک سایت استاتیک فارسی و راست‌چین برای دریافت اطلاعات اولیه متقاضیان مشاوره است.

## عملکرد فرم
- هفت سؤال دارد.
- دکمه «ثبت درخواست مشاوره رایگان» پس از تکمیل هر هفت پاسخ نمایش داده می‌شود.
- پس از ثبت، متن پاسخ‌ها کپی می‌شود و صفحه گفت‌وگوی روبیکا باز می‌شود.
- متقاضی باید متن کپی‌شده را در روبیکا جای‌گذاری و خودش ارسال کند.

**توجه:** این نسخه فرم‌ها را در پایگاه‌داده یا پنل مدیریت ذخیره نمی‌کند و ارسال خودکار پیام به روبیکا ندارد.

## انتشار در Cloudflare Pages
- روش انتشار: اتصال GitHub به Cloudflare Pages
- مخزن: `majnoonierfan-dotcom/mr-muscle-consultation`
- شاخه انتشار: `main`
- دستور ساخت: `exit 0`
- پوشه خروجی: `.`
- پوشه ریشه: خالی (ریشه مخزن)

پس از اتصال مخزن و اولین انتشار، Cloudflare یک نشانی `pages.dev` می‌سازد و تغییرات بعدی شاخه `main` را خودکار منتشر می‌کند.
